**Click the GakrCLI icon in the sidebar or editor toolbar to open a chat panel.**

First, make sure you've installed the CLI and configured a provider (see Step 1). If the CLI isn't installed, GakrCLI will prompt you with install instructions when you try to use it.

You can also use the keyboard shortcut **Ctrl+Escape** (Windows/Linux) or **Cmd+Escape** (Mac) to quickly open or focus GakrCLI from anywhere in the editor.

To open in a dedicated tab, run **GakrCLI: Open in New Tab** from the Command Palette.
